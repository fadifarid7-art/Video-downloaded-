Install the Downloader

A bookmark that adds a download panel to the page you're on. It lists the videos and images it finds, and every download is a real link, so your browser asks where to save it.

1. Copy the code

Open test folder

2. iPhone: Aloha, Safari or Chrome

  1. While on this page, add a bookmark (in Aloha: the menu, then Add bookmark; in Safari: the Share button, then Add Bookmark).
  2. Open your bookmarks, find the new one, and choose Edit.
  3. Rename it to Downloader.
  4. Delete the address and paste the code you copied. Save.
  5. On any page, open your bookmarks and tap Downloader. In Chrome on iPhone, type Downloader in the address bar and tap the bookmark suggestion.

Tap it again to close the panel. Try it first on the test folder.
